# 날씨 가이드

> 분류: 필드·날씨 · 출처: pkmnchamps.com/guide/weather

날씨는 배틀에서 강력한 전략 도구입니다. 각 날씨의 효과와 관련 포켓몬을 파악해 더 강한 파티를 만들어보세요.

- 기본 5턴 지속 / 날씨 연장 도구 장착 시 8턴

## 쾌청

강렬한 햇빛이 배틀 필드를 뒤덮습니다. 불꽃 기술이 강화되고 물 기술이 약해지며, 솔라빔·광합성 등 고유 보너스를 누릴 수 있습니다.

- 🔥 불꽃 타입 기술 위력 ×1.5배
- 💧 물 타입 기술 위력 ×0.5배 (반감)
- 🌿 차지 없이 즉시 사용
- 📈 공격·특공 각각 +2단계 (평상시 +1단계)
- 💚 회복량: 최대 HP의 2/3 (평상시 1/2)
- 🧊 완전동결 상태이상 자동 해제

### 세터 (M-B 합법, 특성 보유)
- **가뭄** (drought): 나인테일, 코터스

## 비

거세게 비가 내립니다. 물 기술이 강화되고 불꽃 기술이 약해지며, 번개·폭풍의 명중률이 대폭 상승합니다.

- 💧 물 타입 기술 위력 ×1.5배
- 🔥 불꽃 타입 기술 위력 ×0.5배 (반감)
- ⚡ 명중률 100% (평상시 70%)
- 🌀 명중률 100% (평상시 70%)
- 😴 사용 즉시 잠들기
- 💚 회복량: 최대 HP의 1/4 (평상시 1/2)

### 세터 (M-B 합법, 특성 보유)
- **잔비** (drizzle): 왕구리, 패리퍼

## 모래바람

거센 모래바람이 몰아칩니다. 바위·강철·땅 타입 외의 포켓몬은 매 턴 피해를 입으며, 바위 타입의 특수방어가 크게 강화됩니다.

- 💥 매 턴 최대 HP의 1/16 피해 (바위·강철·땅 타입 제외)
- 🛡️ 바위 타입 포켓몬: 특수방어 ×1.5배
- 🌿 차지 필요, 위력 반감

### 세터 (M-B 합법, 특성 보유)
- **모래날림** (sand-stream): 마기라스, 하마돈
- **모래뿜기** (sand-spit): 사다이사

## 눈 (싸라기눈)

싸라기눈이 내립니다. 얼음 타입 포켓몬의 방어가 올라가며, 눈보라를 확실하게 맞힐 수 있습니다.

- 🛡️ 얼음 타입 포켓몬: 방어 ×1.5배 (9세대 이상)
- 💥 [8세대 이하] 매 턴 최대 HP의 1/16 피해 (얼음 타입 제외)
- ❄️ 명중률 100% (평상시 70%)
- 🌿 차지 필요, 위력 반감

### 세터 (M-B 합법, 특성 보유)
- **눈퍼뜨리기** (snow-warning): 눈설왕, 배바닐라, 아마루르가

## 화면 라벨 (용어)

- `abilityLabel` = 특성
- `beneficiaries` = 혜택 받는 포켓몬
- `effects` = 날씨 효과
- `extendItem` = 날씨 연장 도구
- `extendTurns` = (+3턴 연장)
- `setters` = 날씨 세터 (자동 발동 특성 보유)
