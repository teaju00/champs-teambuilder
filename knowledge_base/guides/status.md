# 상태이상 가이드

> 분류: 배틀 계산 · 출처: pkmnchamps.com/guide/status (부여 기술·도구 목록은 기술/도구 DB 에서 계산)

상태이상은 배틀의 흐름을 바꾸는 핵심 요소입니다. 각 상태이상의 효과, 면역 타입, 유발 기술, 치료법을 파악해 배틀을 유리하게 이끌어 보세요.

### 잠듦

**챔피언스 수치** (시리즈와 다를 수 있음)
- 최대 지속: 강제로 2턴째에 깸 (외부 수면).
- 확률: 2턴째에 33.3% 확률로 깨고, 3턴째엔 100% 깸.

- 의미: 수면이 강해짐 — 최대 2턴(외부)만으로 풀리므로 장기전에서 운용하기 어려움.

## 부 상태이상 (교체로 해제)

혼란은 포켓몬을 교대하면 즉시 해제됩니다. 또한 독·화상 등 주 상태이상과 동시에 적용될 수 있습니다.

- **혼란** — 부여 기술 14개: 폭발펀치(100%), 매혹의보이스(100%), 수다(100%), 폭풍(30%), 원더스팀(20%), 물의파동(20%), 환상빔(10%), 염동력(10%)
- **속박** — 부여 기술 9개: 마그마스톰(100%), 썬더프리즌(100%), 회오리불꽃(100%), 모래지옥(100%), 집게덫(100%), 바다회오리(100%), 엉겨붙기(100%), 조이기(100%)
- **홀림** — 부여 기술 1개: 헤롱헤롱
- **독/마비/잠듦** — 부여 기술 1개: 페이탈클로(30%)
- **봉인** — 부여 기술 1개: 사슬묶기
- **뿌리박기** — 부여 기술 1개: 뿌리박기
- **씨뿌리기** — 부여 기술 1개: 씨뿌리기
- **멸망의노래** — 부여 기술 1개: 멸망의노래
- **끈적타르** — 부여 기술 1개: 타르샷(100%)
- **음소거** — 부여 기술 1개: 지옥찌르기(100%)
- **방해** — 부여 기술 1개: 트집
- **하품** — 부여 기술 1개: 하품

## 치료 도구

- **리샘열매** — 포켓몬에게 지니게 하면 모든 상태 이상을 회복한다.
- **배리열매** — 포켓몬에게 지니게 하면 얼음을 회복한다.
- **버치열매** — 포켓몬에게 지니게 하면 마비를 회복한다.
- **복분열매** — 포켓몬에게 지니게 하면 화상을 회복한다.
- **복슝열매** — 포켓몬에게 지니게 하면 독을 회복한다.
- **시몬열매** — 포켓몬에게 지니게 하면 혼란을 회복한다.
- **유루열매** — 포켓몬에게 지니게 하면 잠듦을 회복한다.

## 화면 라벨 (용어)

- `cureItems` = 치료 도구
- `curedMoves` = 치료 기술
- `cures` = 치료 방법
- `effects` = 효과
- `immuneTypes` = 면역 타입
- `inflictItems` = 전략 도구 (자해 부여용)
- `inflictMoves` = 부여 기술
- `mainStatus` = 주 상태이상
- `noImmune` = 면역 타입 없음
- `volatileStatus` = 부 상태이상
